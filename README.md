# Library Management API

A RESTful Library Management API built from scratch using Java and Spring Boot.

## 🚀 Project Overview

The Library Management API is a backend application designed to manage library users and books through RESTful APIs.

The project is being developed to practice and demonstrate backend development concepts using Java, Spring Boot, and related technologies.

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Maven
- REST API
- SQL Database
- JUnit
- Git & GitHub
